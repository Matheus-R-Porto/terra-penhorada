# Terra Penhorada (nome provisório)

Protótipo de jogo de fazenda/sobrevivência feito em **GameMaker**, com mecânicas de:
- Plantio e colheita (crop plots)
- Criação de animais (galinhas, coleta de ovos)
- Mineração de minério
- Máquinas automatizadas (alimentador, gerador, irrigador)
- Estações de crafting (fornalha, bancada, fazedor de ração)
- Contratos/entregas, loja e sistema de reputação
- NPCs, inventário, baú de armazenamento e sistema de save/load completo

## Status
Em desenvolvimento / não finalizado — projeto de estudo e prática de sistemas de jogo em GameMaker.

## Como abrir
Requer [GameMaker](https://gamemaker.io/) instalado. Abra o arquivo `.yyp` na raiz do projeto.
